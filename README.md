#### **Personalized Fitness, Nutrition and Transformation Optimization Through Integrated Health Analysis**

An end-to-end algorithmic health intelligence system designed to eliminate generic workout and diet guesswork through individualized biometric modeling, metabolic rate calculations, and contextual fitness assistance.

```text
┌─────────────────┐      ┌─────────────────────────┐      ┌──────────────────────────┐
│  USER BIOMETRIC │ ───► │ 4-ENGINE BIOMETRIC CORE │ ───► │ PERSONALIZED WORKOUT     │
│  & DIET INPUT   │      │ BMI • BMR • TDEE • BF%  │      │ & NUTRITION ENGINE       │
└─────────────────┘      └─────────────────────────┘      └──────────────────────────┘
                                      │                                 │
                                      ▼                                 ▼
                         ┌─────────────────────────┐      ┌──────────────────────────┐
                         │ REAL-TIME TRANSFORMATION│      │ CONTEXTUAL AI ASSISTANT  │
                         │ OPTIMIZATION & TRACKING │      │ RETRIEVAL-AUGMENTED (RAG)│
                         └─────────────────────────┘      └──────────────────────────┘
```

- **Problem:** Fitness seekers struggle with cookie-cutter meal plans and arbitrary workout routines that ignore individualized basal metabolic requirements and body composition ratios.
- **Solution:** An automated analytical framework that computes accurate BMR, TDEE, and optimal caloric macros, coupled with a contextual AI advisor for progressive overload adjustments.
- **Core Engineering Modules:**
  - **Health Analysis:** Mifflin-St Jeor metabolic computation ($BMR_{male} = 10w + 6.25h - 5a + 5$) & body composition ratio estimation.
  - **Macro Allocation:** Automatic protein, carbohydrate, and healthy fat distribution mapped to specific fitness goals (Hypertrophy, Recomposition, Deficit).
  - **Transformation Tracking:** Temporal measurement delta logging with adherence visualizers.
  - **AI / RAG Assistant:** Context-aware exercise library guidance and nutrition rule enforcement.
- **Technologies:** `Python` • `FastAPI` • `React` • `TypeScript` • `Vector RAG` • `Supabase`
