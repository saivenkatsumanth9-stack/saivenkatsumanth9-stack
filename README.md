Explore the interactive **React 19 + TypeScript + Vite + Tailwind CSS v4** developer command center application in [`portfolio/`](./portfolio):

- 💻 **Floating Shell Terminal (`$`):** Interactive CLI (`help`, `projects`, `skills`, `whoami`, `sudo hire-me`).
- ⚡ **Fuzzy Command Palette (`Ctrl+K` / `⌘K`):** Instant search and deep-dive architecture inspection.
- 🔬 **Interactive ReAct Simulator:** Step-by-step visual trace inspector for agentic loops.
- 🎯 **Interactive Tech Matrix:** Click any tech badge to filter and highlight matching builds.

```bash
git clone https://github.com/saivenkatsumanth9-stack/saivenkatsumanth9-stack.git
cd saivenkatsumanth9-stack/portfolio
npm install && npm run dev
```
